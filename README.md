# Crypto Deep Research

Исследования криптопроектов с помощью **Kilo CLI**. Вы задаёте вопрос — проект помогает собрать источники, разобраться в экономике и рисках и подготовить подробный отчёт на русском.

Подходит для вопросов о токенах, доходах протоколов, распределении наград и сценариях развития. Модель и провайдера вы выбираете в Kilo.

## Как это работает

1. **Разбирает вопрос:** определяет, какие данные нужны для ответа.
2. **Собирает материалы:** ищет официальные и независимые источники, сохраняет их для проверки.
3. **Анализирует:** сопоставляет данные, делает расчёты, ищет контраргументы и пробелы.
4. **Проверяет и оформляет:** оценивает достаточность ответа и сохраняет отчёт с выводами, рисками и источниками.

Если данных не хватает, это указывается в отчёте. Предположения не должны выдаваться за установленные факты, а неподтверждённая оценка — за обоснованную стоимость.

## Быстрый старт

Нужны **Linux, Python 3.11+ и Kilo CLI** с настроенной моделью и авторизацией. У Python-части нет внешних зависимостей.

Откройте Kilo из корня проекта:

```bash
kilo "$PWD"
```

В чате Kilo запустите исследование:

```text
/research Aave: откуда берутся доходы, что получает владелец токена и какие есть риски
```

По умолчанию используется глубокое исследование. Быстрый обзор нужно попросить явно.

Дополнительные API-ключи необязательны и перечислены в [`env.example`](env.example). Если используете `.env`, экспортируйте переменные в окружение **до запуска Kilo**: проект не загружает этот файл автоматически. Не сохраняйте реальные ключи в Git.

## Где искать результат

- **`reports/`** — готовые Markdown-отчёты: краткий вывод, подробный разбор, расчёты, риски и источники.
- **`artifacts/runs/`** — сохранённые материалы и расчёты, на которых основаны выводы.

Обе папки исключены из Git. Для повторной проверки существующего исследования без сбора новых источников:

```text
/research-check artifacts/runs/<run-id>
```

## Важно знать

- Сбор ограничен **96 HTTP-запросами и 60 минутами** по умолчанию. Это не ограничение времени работы или стоимости модели в Kilo.
- Доступность источников и полнота данных не гарантированы. Успешная техническая проверка не доказывает достоверность выводов или инвестиционную привлекательность.
- Проект предназначен для анализа: он не торгует, не подключает кошельки и не подписывает транзакции.

## Для разработки

В Kilo выберите агента **`crypto-code`**. Правила работы с кодом — в [`AGENTS.md`](AGENTS.md).

```bash
python3 -m unittest discover -s tests -v
kilo config check --pure
```
